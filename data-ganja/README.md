Put each month's raw Ganja survey Excel report (`.xlsx`) directly in this folder.

Just keep the month name (or 3-letter abbreviation) and the 4-digit year
somewhere in the filename, e.g.:

- PPP_Ganja_July2026.xlsx
- PPP_Ganja_Aug2026.xlsx

No renaming, conversion, or extra steps needed — the GANJA tab of the
dashboard reads this folder automatically on every page load, exactly
like the CAW dashboard reads the `data/` folder.
